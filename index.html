eigen-form

Mathematical design primitives, and the lab that tests them. Every visual element is a rigorously defined mathematical object, parameterized at the level of its governing equations. The mark is a (2, 3) torus knot, a wavefront tracing its orbit against a fading substrate.

Below, every simulation in the lab sits beside the equations it implements and the papers those equations come from. Each implementation links to the exact lines of code it lives in, with a note on how faithfully the code follows the source.
