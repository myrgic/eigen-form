panel · the three control classes

A live defineParams store rendered by renderPanel into a container this page owns. Knobs are writable; the gauge reads the running field; the preregistered decay renders its declaration and a lock — no input element exists for it, by construction. Drag the knobs: the stage is driven by the same store.

palette · hue is data or brand, never both

Brand bands (sampled live from src/palette/gradients.js) color marks and chrome. Measured quantities use perceptually honest maps: monotone ramps for magnitudes, uniform cyclic maps for phases (the cyclic maps arrive with the phase-field family; the ramp below is the shape of the rule, not a shipped map). One figure never mixes the two modes.

theming · custom-property flow-through

Each button overrides token properties on this document's root and nothing else. Every module above — panel, badges, tabs, swatches, stage — follows, which is the whole theming contract: reflow the layout, rewire the theme, never fork the modules.
